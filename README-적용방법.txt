BLOSSOM 메인 공지사항 자동 연동 v12
================================

이번 수정은 홈페이지의 📢 길드 공지사항 카드만 변경합니다.
기존 회원가입·숙제·버프·이벤트 타임라인·출석·BP 상점 기능은 유지합니다.

1) Github 로그인 후 gktmddn07101825-coder/blossom-home 저장소를 엽니다.
2) 기존 index.html을 이번 ZIP의 index.html로 교체합니다.
3) home-notices.js를 index.html과 같은 최상위 폴더에 새로 올립니다.
4) Commit changes를 클릭합니다.
5) https://blossomdm.kr/?v=12 로 접속해 회원 로그인 후 확인합니다.

주의: 이번 index.html은 기존 BLOSSOM v11 홈페이지 파일을 기준으로
공지 로딩 문구와 JS 로딩 한 줄만 수정했습니다. 최근 다른 곳을 직접
수정한 적이 있다면 전체 교체 대신 다음 두 부분만 반영하세요.

[직접 수정 방식]
- 현재 index.html의 기존 공지사항 안내 .notice 영역은 그대로 둬도 됩니다.
  새 스크립트가 실행되면 자동으로 최신 공지 목록으로 대체됩니다.
- </body> 바로 앞에 다음 한 줄만 추가하면 됩니다.
  <script src="home-notices.js?v=12" defer></script>

[작동 방식]
- '이벤트 & 공지' 페이지의 게시물 중 '공지사항' 종류만 표시합니다.
- 로그인한 회원만 공지를 볼 수 있습니다(기존 blossom-events 권한 정책).
- 최신순 최대 3개; 클릭하면 본문 전체를 팝업으로 표시합니다.
- 수정·삭제한 내용은 페이지 갱신 또는 약 90초마다 다시 읽습니다.
- 관리자/운영진이 원래 게시판에서 작성하는 방식은 그대로 유지됩니다.
- Supabase SQL과 Edge Function은 수정하지 않습니다.
